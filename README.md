# Projeto Rick and Morty - Front-End

Projeto acadêmico desenvolvido somente com HTML, CSS e JavaScript.

## Como executar
1. Extraia a pasta.
2. Abra o arquivo `index.html` no navegador.
3. Para uma experiência mais confiável, use o Live Server do VS Code.

## API utilizada
Rick and Morty API:
https://rickandmortyapi.com/

O JavaScript utiliza `fetch()` para consultar a API. Os cards são criados
dinamicamente com `document.createElement()` e adicionados ao HTML com
`appendChild()`.

## Arquivos
- index.html: estrutura da página.
- style.css: estilos e responsividade.
- script.js: consumo da API e criação dos cards.
